# REQUIRED packages of the octarine-os dx image (ghcr.io/redcodeworks/octarine-bins-dx, /packages/required-fedora.txt): Fedora's own repositories, ONE strict dnf5
# transaction (installer/install.sh): a name that cannot be installed fails the build. The toolchain, the -devel libraries and the core of VM hosting.
# One token per line; blank lines and #-comments ignored (@group-id is a package group; a|b are ALTERNATIVES for a package whose name differs between Fedora
# releases: the first one that exists is installed, newest name first). Syntax and policy: CLAUDE.md, "The package lists".
# (the developer list moved here from octarine-images' dev-packages on 2026-11-16; the VM-hosting set from octarine-os's variants/dx/packages/extras.txt)
#
# - Do NOT add ffmpeg-free-devel: libGLU cannot install once Fedora's mesa is excluded in favour of another Mesa.
# - ROCm (rocminfo rocm-smi rocm-hip rocm-opencl hipcc, about 3 GiB) is deliberately NOT in this image: `ujust hardware-setup` (step rocm) provides it in a rootless distrobox.
# - The default image already carries gcc, gcc-c++, make and binutils; dnf5 skips what is installed.
